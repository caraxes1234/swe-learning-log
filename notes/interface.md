# Java Interfaces

An interface is a contract. It tells a class what to do, but not how to do it.


Most interface methods have no body, except for two types:
Default Methods (`default`)
   * Have a body.
   * Inherited by the class automatically.
   * Rule:** The class can use it as-is or override it.

2. Static Methods (`static`)
   * Have a body.
   * Belong strictly to the interface.
   
* All variables are automatically **`public static final`**.
*  They are constants. They must be given a value immediately, and that value cannot be changed.
