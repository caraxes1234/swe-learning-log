
**Binary Search** is a searching algorithm used to find an element in a dataset.

Finding an element using **linear search** can take **O(n)** time because we may have to check every element one by one. This can be inefficient for large datasets.

Binary search improves this by **reducing the search space by half after each comparison**. This makes it much faster than linear search for large datasets.

The time complexity of binary search is **O(log n)**.

One important requirement is that **binary search can only be performed on sorted data**.
